# Heygen Clone

A modern AI-powered video generation platform clone with a beautiful, responsive frontend interface.

## 🚀 Features

- **AI Avatar Selection**: Choose from 6 different AI avatars
- **Multi-language Support**: Create videos in 8+ languages
- **Voice Customization**: Select from 5 different voice styles
- **Background Options**: 4 preset professional backgrounds
- **Real-time Preview**: Interactive video generation with progress tracking
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Modern UI**: Beautiful gradients, smooth animations, and professional design

## 🎯 Getting Started

### Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. Start creating videos!

### Using a Local Server

```bash
# Using Python 3
python3 -m http.server 8080

# Then open http://localhost:8080 in your browser
```

## 📁 Project Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality

## 💡 How to Use

1. **Choose Your Avatar**: Click on any of the 6 available avatars
2. **Write Your Script**: Enter your video script (max 500 characters)
3. **Select Language & Voice**: Choose your preferred language and voice style
4. **Choose Background**: Pick a background that matches your style
5. **Generate Video**: Click the "Generate Video" button and watch the magic happen!
